# 프로필 사진 넣기

현재 SVG는 글자와 테두리만 있는 자리 표시자입니다. 인물 사진은 생성하지 않았습니다.

1. 본인 사진을 이 폴더에 `profile.jpg`로 저장합니다. PNG이면 `profile.png`를 사용합니다.
2. 프로필 README 첫 줄을 아래처럼 수정합니다. 파일명과 확장자는 실제 파일과 일치해야 합니다.

```html
<img src="assets/profile/profile.jpg" alt="김조은 프로필 사진" width="120" align="right">
```

사진 없는 구성을 원하면 프로필 README 첫 줄을 삭제합니다. GitHub 계정 아바타는 계정 설정에서 별도로 지정합니다.
